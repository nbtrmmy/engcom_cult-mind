# engcom-artwork

Artwork that represents Cult Mind, one category of why it is difficult to be conscientious (ENGCOM Conscientiousness Project 2026).

Built with plain HTML, CSS and JavaScript (Canvas 2D). No libraries and no build step.

## What it shows

A small, panicked pink ghost stands in the middle of a crowd of identical ghosts holding hands. Nobody is hostile. They just smile and stare, and move exactly together. The pressure is felt by the one being watched.

## Files

- `index.html`: the artwork. Open it in a browser.
- `video/`: screen recordings used in the slides (not tracked in git).
